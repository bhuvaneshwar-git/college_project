### Prerequisites
- Docker
- node js
- react 
- vite ( for local deployement )
- sqlite ( database )
- git
- Authgear ( for authetication ) no installation needed 

## Installation 

# 1 Clone the repo
```
git clone https://github.com/bhuvaneshwar-git/college_project.git 
cd college_project
```
# 2 setup backend
```
npm install

```
